# ITDA · 회수·반품 검토 시연

본선 발표 09 시연용 HTML과 직접 조작형 모바일 UI입니다.

- [발표 애니메이션](https://hyeminhassomething.github.io/itda-pharmacy-demo/)
- [데모 앱](https://hyeminhassomething.github.io/itda-pharmacy-demo/app.html)

## 실행

발표 화면에서 **재생**을 누르면 2분간 검수 → 거래 연결 → 회수 범위 → 실사 → 검토 목록을 보여줍니다. Space: 재생/정지, 방향키: 장면 이동, R: 처음.

앱에서는 시연 원문 불러오기 → 원문 대조 체크 → 검수 확인 → 가상 매입 기록 연결 → 공지 범위 확인·대조 → 실사 3개 확인 → 검토 목록 순서로 진행합니다. CSV를 직접 내려받을 수 있습니다.

## 시연 범위

품목·표기·OCR 원문·거래·공지·반품 규칙은 합성 자료입니다. 실제 약품 사진·OCR 모델·약국 전산·공공 회수 API와 연결되지 않았으며, 실제 반품 신청이나 의료적 판단을 수행하지 않습니다.

검수 상태 전환, 수량 범위 계산, 입력 수정 후 결과 무효화, 시연 규칙에 따른 상태 분류와 CSV 생성은 브라우저에서 실행됩니다. 자동 재생의 확인 동작은 실제 약사의 승인이 아닙니다. 입력은 서버로 전송하거나 영구 저장하지 않습니다.

기준일은 2026-10-03입니다. X 4개·Y 6개 입고와 총재고 8개라는 예시에서 X 잔량은 조건부 2–4개이며 실사값으로 3개를 입력합니다. 기록의 완전성과 총재고 정합성이 전제입니다. 재고 감소를 판매라고 단정하지 않습니다.

회수 검토는 일반 반품 기간 판단과 분리합니다. 규칙 미확인은 보류하며 CSV는 검토 자료이지 접수 완료가 아닙니다. 2분은 재생 길이로, 처리 속도 실측이 아닙니다.

## 파일 및 수정

- `index.html`: 자체 포함형 발표 화면
- `app.html`: 자체 포함형 데모 앱
- `src/demo-engine.js`: 시연 계산·검수 상태·CSV
- `src/demo-ui.js`: 앱 및 재생 제어
- `src/demo.css`: 화면 스타일
- `src/build.mjs`: 두 HTML 생성

소스를 수정하면 Node.js에서 `node src/build.mjs`를 실행한 뒤 생성된 HTML과 소스를 함께 커밋합니다. 추가 패키지는 필요하지 않습니다. GitHub Pages는 `main` 브랜치의 루트에서 배포합니다.

## 확인 내역

엔진 단위검증 20항목, 네트워크 차단 Chrome의 브라우저 동작 검증 31항목, 120초 재생 종료·최종 상태를 확인했습니다. 이 검증은 실제 약품 OCR 성능이나 현장 반품 규칙의 정확도를 뜻하지 않습니다.
